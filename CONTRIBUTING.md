# Contribuyendo a Mi Galería

Gracias por tu interés en mejorar este proyecto.

## Reglas de Oro

1. **Simplicidad ante todo:** Si una función o elemento visual no tiene una función crítica demostrable, se elimina. El minimalismo es la optimización máxima.
2. **Cero Dependencias:** No se aceptan frameworks pesados. Todo se desarrolla en Vanilla (HTML, CSS y JavaScript puro) utilizando CSS Grid, SVG y geometría vectorial.
3. **Optimización Extrema:** Cada línea de código debe justificarse por su eficiencia y su bajo consumo de recursos en cualquier dispositivo.

Para proponer cambios, abre un **Pull Request** con una explicación técnica detallada de la mejora.
