# Changelog - Mi Galería

## [1.1.0] - 2026-07-28

### Added
- Configuración de arquitectura PWA (Progressive Web App) con `manifest.json` y Service Worker para instalación nativa en dispositivos.
- Archivo `.gitignore` para exclusión limpia de archivos de sistema, cachés y configuraciones de IDE.

### Changed
- Estilo y tipografía de la interfaz optimizados con tipografía de imprenta rústica, efectos dinámicos de brillo en reposo y transición de zoom en hover.

## [1.0.0] - 2026-07-27

### Added
- Versión inicial estable (V1) de la galería digital de libre acceso.
- Estructuración base nativa con HTML, CSS y JavaScript orientada al rendimiento y minimalismo.
